# TaoBao User Behavior Analysis

## 1. 项目简介

本项目基于阿里云天池提供的淘宝用户行为数据，对用户的**点击、收藏、加购、购买**等行为进行分析。

项目从用户行为路径出发，围绕电商运营中的转化、用户价值、留存和复购等问题，实践从**数据清洗 → 指标计算 → 用户行为分析 → 可视化 → 业务洞察**的完整数据分析流程。

数据来源：[阿里云天池 - 用户行为数据集](https://tianchi.aliyun.com/dataset/649)

---

## 2. 项目背景

海量的用户行为数据中隐藏着用户从浏览到购买的决策过程。本项目主要围绕以下几个业务问题展开：

* **转化瓶颈识别**：通过漏斗分析了解用户在浏览、收藏、加购和购买环节中的流失情况。
* **用户价值分层**：使用 RFM 模型对用户进行分层，识别不同价值用户群体。
* **大促节奏分析**：分析双十二期间的用户行为变化及流量波动，观察用户活跃和回流规律。
* **存量经营分析**：通过留存和复购分析，了解用户忠诚度及持续购买行为。

## 5. 分析内容

### 5.1 用户行为分析

分析用户点击、收藏、加购和购买等行为，了解不同用户行为在整体用户活动中的分布情况。

### 5.2 转化漏斗分析

通过用户行为路径分析不同环节的转化情况，识别用户从浏览到购买过程中的主要流失环节。

### 5.3 RFM 用户价值分析

基于用户最近购买时间（Recency）、购买频率（Frequency）和购买金额（Monetary）对用户进行分层，识别不同价值用户群体。

### 5.4 留存分析

通过用户在不同时间段的行为情况分析用户留存及回流情况，观察大促期间用户活跃度的变化。

### 5.5 复购分析

分析用户重复购买行为，了解平台用户的持续购买情况及用户忠诚度。

---

## 6. 核心分析结论

基于 **2017 年 11 月 25 日至 12 月 3 日**的用户行为数据，得到以下主要分析结果：

### 高复购特征

全站复购率约为 **65.81%**，从数据层面反映出较高的用户重复购买行为。

### 加购行为具有较强的转化信号

加购行为频次约为收藏行为的 **2.05 倍**。进一步分析用户行为时间间隔后发现，加购后的短时间窗口内用户转化更加集中。

### 周末与大促期间用户活跃度变化明显

留存分析显示，**12 月 2 日（周六）**出现明显的用户行为变化，部分用户群体的回流率超过 **90%**。

### 用户价值存在明显分层

RFM 分析显示，不同用户群体在活跃度和购买行为方面存在明显差异，其中约 **34% 的重要价值用户**贡献了较高的用户活跃度。
